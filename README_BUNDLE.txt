MARSCOPE RELEASES BUNDLE
========================

This bundle contains two separately versioned source projects:
  MARSCOPE-v0.1.0/  Initial prototype
  MARSCOPE-v0.3.1/  Expanded prototype

Extract both folders. They are intentionally named separately so that
one release does not overwrite or merge into the other.
For setup, read DOWNLOAD_FIRST.txt and README.md inside each folder.
