# MARSCOPE 0.4.0 release notes

The runnable MARSCOPE source tree is at the **repository root**:

- \`backend/\`
- \`decision-service/\`
- \`frontend/\`
- \`docs/\`
- \`render.yaml\`

This folder preserves the 0.4.0 release notes and example environment configuration. It is not a self-contained source archive. The launchers previously described here (\`RUN_MARSCOPE.bat\`, \`RUN_MARSCOPE.ps1\`, and \`run.sh\`) are not part of this repository and should not be used.

For accurate setup instructions, open the [repository README](../README.md). It starts the three services separately and explains the shared backend-to-Jev service token.

The Jev request architecture, fallback behaviour, and Render configuration are documented in [JEV-INTEGRATION.md](../docs/JEV-INTEGRATION.md).
